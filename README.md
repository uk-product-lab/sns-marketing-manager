# SNS Marketing Manager

更新日: 2026-09-16

複数ブランドのInstagram、X、TikTok、note向けコンテンツを、MacとiPhoneから準備・検索・再利用するための個人用レスポンシブWebサービスです。

MVPでは媒体別原稿、画像スライド、短尺動画、投稿予定、手動投稿パックを扱います。投稿用の文章をコピーし、素材を取得して、各SNSへの投稿は利用者が行います。

最終的には長編動画・録音・写真・文章を受け取り、専門担当が連携して、同じ企画からSNS投稿、note記事と販売先URL、LPを作る制作基盤へ拡張します。生成・プレビューと外部公開は分けます。この最終構想をすべて初期MVPへ前倒しするものではありません。

## MVPの5機能

1. ブランド・運用アカウント管理: ブランドごとにInstagram、X、TikTok、noteのアカウントを登録する。
2. 投稿企画・媒体別原稿: 共通企画から媒体別の本文、ハッシュタグ、リンク、代替テキストを編集・保存し、まとめてまたは個別にコピーする。
3. 素材ライブラリ: 文章、下書き、過去投稿、画像、動画をブランド・媒体・タグ・日付などで検索し、複製・再利用する。
4. 投稿カレンダー: 日本時間の投稿予定を一覧・週・月で管理し、画面を開いた際に予定時刻を過ぎた投稿を「要手動」として表示する。
5. 手動投稿パック・状態管理: 原稿、素材、投稿順、チェックリストをまとめ、投稿後にURLと公開日時を記録する。

## 利用条件と素材

- Mac mini、MacBook、iPhoneに対応するレスポンシブWebサービス。将来PWA化を目指す。
- 画像スライドは最大10枚。並べ替えと連番付きの取得に対応する。
- 動画は主に15〜30秒、縦長9:16の完成済み動画を扱う。
- 投稿キャプション（本文・ハッシュタグ）を編集・コピーできる。
- 動画内字幕は文章と時刻の編集、重ね合わせプレビュー、SRT・WebVTTの取得を初期要件とする。音声からの自動字幕生成は未決、字幕を焼き込む動画出力は次期対応。
- 状態は媒体ごとに「下書き／編集中／投稿準備完了／投稿予定／要手動／投稿済み／見送り」を管理する。「投稿予定」はアプリ内の予定で、SNS側の自動予約投稿ではない。
- 初期は個人利用。利用者とブランドの所属をデータに持たせ、将来の複数利用者対応に備える。

## 費用と認証

- 追加課金が発生する外部サービスやSNS APIはMVPに導入しない。
- Cloudflareを第一候補とし、無料枠・上限・課金停止方法を実装前に確認する。R2などの自動従量課金を防げる運用が成立するまでは本番利用を開始しない。
- 素材の容量と使用量を記録し、容量増加時の扱いを利用者が判断できるようにする。
- 独自ドメイン購入は後回し。初期の公開URLは `workers.dev` を候補とする。
- Google Workspaceは未契約で、利用の前提にしない。
- Google AI Proは契約済み。非公開Driveを素材庫、Mac miniを制作処理の実行先にする案は検討中で、R2との役割分担・API利用条件は未確定です。
- Better AuthでGoogle認証とメールアドレス・パスワード認証を用意する。個人利用時は登録可能な利用者を制限する。
- 一般向け公開前にメール確認、パスワード再設定、アカウント連携の安全性を検証する。

## 既存スターターの起動

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。ビルドは `npm run build`、ビルド結果の確認は `npm run preview` です。

- `src/index.html`: 画面の土台
- `src/styles.css`: 見た目のスタイル
- `src/main.js`: 動作確認ボタン

現在のスターターはJavaScriptとViteの最小構成です。次の技術構成はSNS管理機能を実装する際の方針です。

## 技術方針

- React + TypeScript + Vite
- Cloudflare Workers

- 原本庫として非公開Google Drive、制作処理としてMac miniを比較検討（未決）
- Better Auth
- PlaywrightによるChromium・WebKit E2E
