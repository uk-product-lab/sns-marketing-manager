# 実装チェックリスト

## 受領

- [ ] タスク状態が`READY`
- [ ] 受け入れ条件が検証可能
- [ ] 対象外が明記
- [ ] 依存タスクが`POST_MERGE_PASS`または`DONE`
- [ ] 料金・外部作用・秘密情報の未決事項なし
- [ ] 専用branch・worktree
- [ ] 実装lease取得済み

## 差分

- [ ] 1つの利用者価値に限定
- [ ] `sources/`変更なし
- [ ] 無関係な整形・リファクタリングなし
- [ ] DB変更にマイグレーションあり
- [ ] ユーザーデータ分離を維持
- [ ] 新フローのテストと回帰manifest昇格が同じPR

## 検証

- [ ] 型チェック
- [ ] Lint
- [ ] 単体・結合テスト
- [ ] Production build
- [ ] D1初期・更新マイグレーション
- [ ] ブラウザ予備確認
- [ ] 外部SNS API通信なし
- [ ] 秘密情報なし

## 引き継ぎ

- [ ] 固定コミットSHA
- [ ] 受け入れ条件とテストの対応
- [ ] 既知の制約
- [ ] 生のテスト結果
- [ ] スクリーンショット
- [ ] 状態`SELF_TESTED`
- [ ] CEOが実装leaseを`SELF_TESTED`で解放
